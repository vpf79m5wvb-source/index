# CardSwipe MTG v6

This build adds subtype filtering on top of the stable v5-fixed version.

## New in v6
- Quick subtype chips: Elf, Goblin, Dragon, Zombie, Vampire, Wizard, Human, Equipment, Vehicle, Aura.
- Custom subtype field in Filters, so you can type any subtype such as Angel, Dinosaur, Time Lord, Shrine, Treasure, Forest, and more.
- Subtype combines with existing filters. Example: Green + Creature + Elf.
- Keeps the loading race-condition fix from the stable build.

Replace the files in your GitHub Pages branch with this build. After deployment, open the site in Safari and refresh it once before reopening the Home Screen app.
